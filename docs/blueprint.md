# **App Name**: Adioumani Jean, Network & Web Developer

## Core Features:

- Responsive Two-Column Layout: Establishes the core visual structure (sidebar + content), adapting seamlessly across all screen sizes for optimal viewing.
- Navigation Sidebar with Profile: A vertical, fixed-position menu on the left, featuring the user's profile image, main navigation links (e.g., Home, About, Projects), and social media icons.
- Dynamic Project Showcase: Displays recent projects with compelling images, titles, brief descriptions, and 'view case study' links in a grid or gallery format.
- Client Testimonial Display: Presents client reviews and feedback, including star ratings, client names, and their valuable quotes.
- Technology Stack Visualizer: Showcases the user's skills and preferred tools/technologies using visually appealing logos and icons.
- AI Content Assistant Tool: An internal tool to assist Patricia in generating ideas and refining textual content for her project descriptions or 'About' section, enhancing clarity and impact.
- 'Let's Connect' Call to Action: A prominent section with contact information or a clear call-to-action button, encouraging visitors to get in touch.

## Style Guidelines:

- Color Palette: Dark mode theme evoking digital professionalism. Primary color: a vibrant emerald green (#00CC50) for interactive elements and highlights, providing clear contrast against dark backgrounds. Background color: a subtly dark, near-black shade (#0C0F0D) with a hint of green hue to maintain visual cohesion. Accent color: a more muted mossy green (#529926) for secondary details or subtle gradients. Text will primarily be off-white for readability on dark surfaces, with lighter grey for supplementary information.
- Body and headline font: 'Inter' (sans-serif) for a modern, objective, and highly legible look, suitable for both large headings and body text to maintain a clean and efficient aesthetic.
- Clean, minimalist line icons for navigation within the sidebar, transitioning to solid, filled icons for social media links. Company and technology logos will be displayed as high-fidelity SVG assets in the 'Stack' section. Star ratings will use simple, filled star icons.
- A persistent two-column desktop layout featuring a fixed-width vertical sidebar on the left (approximately 25% of viewport width) and a fluid, scrollable content area on the right (approximately 75%). This layout gracefully collapses into a single-column stack on smaller mobile and tablet viewports to ensure optimal responsiveness and readability.
- Subtle and refined hover effects for interactive elements such as navigation links, project cards, and buttons, providing tactile feedback. Smooth scroll animations for inter-page navigation, creating an elegant and fluid user experience without unnecessary distractions.
